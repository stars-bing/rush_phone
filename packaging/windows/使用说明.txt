RushPhone Windows 一键版（Windows 11 x64）

1. 安装系统 Google Chrome。无需安装 Python、pip、Node.js 或 Playwright。
2. 完整解压压缩包，双击 RushPhone 文件夹中的 RushPhone.exe。
   _internal 文件夹必须与 EXE 放在一起，不能只复制 EXE。
3. 点击“登录”，在专用 Chrome 窗口手动登录 Apple 并完成验证，保留窗口。
4. 选择“购买 Duo”或“购买 Pro Max”，程序持续等待购买按钮可用。
   默认只演练到最终提交前。真实下单需先勾选“允许提交订单”。
5. 下单后留在原 Chrome 核对订单并手动付款。

默认规格：
  Duo：iPhone Duo / 512GB / 夜空色
  Pro Max：iPhone 18 Pro Max / 512GB / 勃艮第酒红色

配置、日志和登录资料自动保存在 %LOCALAPPDATA%\RushPhone。
点击“打开配置和日志目录”可找到 duo.toml、pro-max.toml 和 logs。
修改规格后保存配置，下次点击购买时会重新读取。已有配置不会被升级覆盖。
两份配置的启用账号名称与 profile_dir 必须相同，才能复用同一登录窗口。
登录资料仅保存在本机，不包含在安装包中；换电脑需要重新手动登录。

“停止”或关闭启动器会等待当前网页操作结束，保留 Chrome。
最终提交已发出后无法撤回；如果订单结果待确认，请先核对原页面和订单，
核对后再重新启动本程序，不要直接重复购买。
同一用户只运行一个启动器，同一账号同时只允许一个购买或演练任务。
Chrome 窗口需保持可见，本机不休眠。

结账和订单成功页面的选择器沿用现有配置，真实网站流程仍需演练核对。
遇到 HTTP 541、登录验证或结账问题时查看原 Chrome 和本地日志。
